# AxiomFlow — thesis-style research manuscript outline (not a PhD degree)

1. Problem definition: deterministic monetary and typed workflow computations.
2. Related work: Python Decimal, Java BigDecimal, JS big-decimal libraries, C/C++ decimal options, DSLs.
3. Grammar, typed value judgments, Decimal arithmetic/rounding semantics.
4. Parser, interpreter, terminal CLI and resource policy.
5. Correctness: edge cases, seeded reference oracle, fuzzing, regression tests.
6. Comparison: fair benchmarks with identical behavior, repeats, confidence intervals, startup, memory, complexity.
7. Reproducibility: pinned toolchains, OS, seeds, CI, datasets, scripts.
8. Threats to validity: interpreter overhead, unsupported workloads, no sandbox, narrow DSL scope.
9. Future extensions: functions, modules, dependency resolver, integrations, independent compiler, terminal.
10. Claims supported only by actual measurements.

Status: **outline**, not a completed, defended or peer-reviewed doctoral thesis.
