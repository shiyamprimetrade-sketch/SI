# SI 100k target — v0.19 status and acceptance roadmap

The requested 100,000/1,000,000 milestone is a **target** measured by evidence, not an amount to award immediately. Starting cumulative self-assessed SI score for v0.19: **1,700/1,000,000**. Historical archive: **996667/1000000**, never merged into the new ledger.

Versioned criteria remain in `docs/milestone_100k.md` (inherited from v0.18). Typed functions and hashed offline local modules advance two gate areas: grammar/types and dependency/build tooling. They do **not** complete the entire 18,000-point language gate or 12,000-point dependency/terminal gate. Gate rewards require integrated acceptance tests, CI and released documentation.

Immediate priorities after v0.19: more complete call semantics and packaging; API/backend + browser/frontend vertical slice; data/ML reference workloads; fair baseline benchmarks across relevant implementations; terminal packaging; reproducible course and thesis-style report. No proof of cross-language universal superiority is possible from a finite suite.

Points for v0.19 will be scored only after observing the actual GitHub CI, with no double count for existing 295 regression tests.
